## Pre-draft release gate

After plans 001–003, require all of the following before relying on the app:

```bash
npm ci
npm run check
npm test
npm run build
npm audit
git diff --check
```

Also perform the real-draft preparation and live-sync smoke tests in
`docs/WORKFLOW.md`. A Linux package is not Windows evidence; use the Windows CI
package smoke and, for an installer release, a clean Windows profile.
