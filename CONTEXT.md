# Sleeper Draft Assistant

Sleeper Draft Assistant separates provider evidence from the advice Codex derives from it. These terms keep draft and in-season value signals explicit rather than treating every ranking as interchangeable.

## Language

**Season value rankings**:
Scoring-specific expert rankings used as long-horizon Team Manager evidence. The active source is either ROS ECR or, before ROS is available, draft ECR fallback.
_Avoid_: ROS rankings when referring to both source types

**ROS ECR**:
Rest-of-season expert consensus rankings that account for the remaining regular season. ROS ECR supersedes draft ECR fallback for the same league season and scoring format.
_Avoid_: In-season rankings, season rankings

**Draft ECR fallback**:
Preseason expert consensus rankings retained as provisional season-value evidence until matching ROS ECR is imported. It remains useful through Week 1 but is not represented as rest-of-season evidence.
_Avoid_: ROS rankings, stale rankings
