# Triage labels

The engineering skills use five canonical triage roles. This table maps those roles to this repository's GitHub label vocabulary.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | The work is fully specified and suitable for an agent |
| `ready-for-human` | `ready-for-human` | The work requires human implementation or judgment |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a triage role, use the corresponding tracker label. Change the tracker-label column if this repository later adopts different label names.
