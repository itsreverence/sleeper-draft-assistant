# Sleeper Draft Assistant 0.1.0

This is the first stable release. Its app code is unchanged from
[0.1.0-beta.6](0.1.0-beta.6.md). The package now also includes
`resources\THIRD_PARTY_NOTICES.txt`, which holds the licenses of the bundled
open-source code and fonts ([#68](https://github.com/itsreverence/sleeper-draft-assistant/pull/68)). Version 0.1.0 is still early, unofficial
software. Releases before 1.0 may change stored data or behavior between
versions, and any such change will be stated in the release notes. Close beta.6
and back up the complete app-data directory before upgrading.

## What it does

- Connects to Sleeper by username, league or draft through Sleeper's
  tokenless, read-only API. Sleeper is the only supported fantasy platform.
- Follows live and completed drafts with a draft board, sync age, retry
  backoff, and the last valid state when Sleeper is unreachable. A synthetic
  demo draft needs no account.
- Imports your own FantasyPros exports: draft ECR, rest-of-season rankings,
  season and weekly projections, and ADP. Imports show how many players matched
  and warn when the data is old.
- Answers draft, roster, lineup, waiver and post-draft questions through your
  locally installed Codex CLI, using the imported evidence. With web search on,
  it can check current NFL.com and ESPN injury or practice reporting and cite
  dated sources.
- Keeps everything in a local SQLite database, with redacted support reports,
  per-category clears and a typed full reset.

## Tested platforms

It is tagged only after the every-release real Windows smoke passes on its

## Install safely

Artifacts are **not code-signed**, and Windows SmartScreen may warn that the
publisher is unknown. Download only from this repository's Releases page and
compare each file's SHA-256 with `SHA256SUMS.txt` before running it. See
[INSTALLING.md](../INSTALLING.md).

## Requirements and limitations

- Access is read-only. The app does not submit picks, change lineups or modify
  your Sleeper account.
- You supply your own ranking and projection exports. No third-party ranking
  data is bundled.
- The normal assistant workflow requires a locally installed, signed-in Codex
  CLI, which the app runs through its supported app-server integration. During
  an active draft, board-only recovery remains available when setup or Codex
  is unavailable.
- Treat AI advice as advisory and check it yourself. News lookups can time out
  or find no recent reporting.
- Custom scoring and TE-premium accuracy depend on imports that match your
  league. IDP and auction drafts are unsupported. Dynasty and keeper valuation
  is not modeled.
- News research threads disable Codex's built-in shell, browser, computer-use,
  app and plugin tools. MCP servers you have configured in your own Codex
  setup are not disabled.

## Local data and removal

Data normally lives under `%APPDATA%\Sleeper Draft Assistant`, with the
database in its `data` directory. Settings offers per-category clears and
**Delete all local app data**. The uninstaller keeps local data. Close the app
before deleting files by hand: delete `data` to remove your records, or the
whole directory to also remove renderer preferences.

## Rollback

To roll back:

1. Close 0.1.0.
2. Restore the app-data backup you made before upgrading.
3. Reinstall 0.1.0-beta.6 from its original release.

Never restore a backup while either version is running.
