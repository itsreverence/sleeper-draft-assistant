# Sleeper Draft Assistant 0.1.0-beta.6

This is a Windows prerelease for testing, not approval of a stable release. Complete the
real Windows smoke before tagging. Beta updates may break compatibility. Before
upgrading, close beta.5 and back up the complete app-data directory.

## Changes

- News lookups have more time. Each lookup gets up to 45 seconds instead of 20.
  The answer's 60-second generation timer pauses while research runs, and a
  hard limit, 150 seconds by default, still bounds the whole answer. Quitting or
  cancelling still closes research processes.
  See [#63](https://github.com/itsreverence/sleeper-draft-assistant/pull/63).
- Citation checks now drop an invalid source, such as an undated or stale
  report, on its own instead of rejecting the whole lookup. Other recent,
  dated sources on approved hosts are kept. The seven-day window, exact-host
  allowlist and two-lookup limit are unchanged.
  See [#63](https://github.com/itsreverence/sleeper-draft-assistant/pull/63).
- Codex threads run with fewer tools. News research turns off apps, plugins,
  browser and computer automation, shell, subagents, image tools, skills, hooks
  and similar built-in features. Hosted web search stays on, limited to NFL.com
  and ESPN. MCP servers from your own Codex configuration are not turned off.
  The main assistant thread turns off apps, plugins, browser and computer
  automation, and shell.
  See [#64](https://github.com/itsreverence/sleeper-draft-assistant/pull/64).
- Choosing a FantasyPros ADP file for season value rankings now explains that it
  is an ADP file and names the export to use instead.
  See [#64](https://github.com/itsreverence/sleeper-draft-assistant/pull/64).
- `@hono/node-server` is updated to 2.1.5, which fixes
  [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f). The
  app does not use the affected static-file helper. A low deepmerge advisory in
  the Svelte build tooling has no fix yet and is not shipped in the app.
  See [#64](https://github.com/itsreverence/sleeper-draft-assistant/pull/64).

## Manual checks

Tag this version only after the every-release
[real Windows smoke](../RELEASING.md#real-windows-smoke) passes on the exact
tagged commit's CI candidate.

The beta.5 [once-before-stable pass](beta.5-validation-followup.md) covered
everything except news retrieval. On this build, with web search on, ask about a
rostered player's current injury or practice report. Confirm that a dated NFL.com
or ESPN citation comes back and opens in the default browser, and that
`newsLookups` in Copy diagnostics shows `available`. Checking this on Windows
completes the once-before-stable pass. A Linux run does not prove Windows
behavior.

## Safety and rollback

Artifacts are unsigned and may trigger SmartScreen. Install only this repository's
release artifacts after checking their SHA-256 checksums. Sleeper is the only
supported fantasy platform. Access is tokenless and read-only. The app does not
submit picks, change lineups, or modify your Sleeper account.

Supply your own ranking and projection exports. No third-party ranking data is
bundled. Normal AI use requires a locally installed, authenticated Codex CLI that
the app runs through its supported app-server integration. During an active
draft, board-only emergency recovery stays available when setup or Codex is
unavailable. Check AI advice before acting on it. IDP and auction advice are
unsupported. Dynasty and keeper valuation is not modeled, and custom scoring is
only as accurate as your imports. News lookups can still time out or find no
recent reporting.

Local data normally lives under `%APPDATA%\Sleeper Draft Assistant`, with the
database in its `data` directory. Settings offers clearing a single data
category and **Delete all local app data**. Uninstalling keeps local data.
Close the app before deleting files by hand: delete `data` to remove your
records, or the whole application-data directory to also remove renderer
preferences.

To roll back, close beta.6, restore the backup made before the upgrade, then
reinstall beta.5 from its original release. Never restore a backup while either
version is running.
