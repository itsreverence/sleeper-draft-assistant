Windows testing candidate, not stable-release approval. Manual validation of this installer remains pending. Back up the complete app-data directory while the app is closed before upgrading.

## Changes

- Pasting weekly CSV now clears the native file chooser as well as the parsed file selection. Selecting the same file again works normally.
- Adds isolated Chromium checks for dialog focus/scrolling, ROS and weekly imports, replacement/clearing, week selection, and delayed responses after reset/reconnection. These use synthetic data and do not certify live services or Windows installer behavior.

## Safety and rollback

Artifacts are unsigned and may trigger SmartScreen. Windows is the distribution target; Linux Chromium checks are not manual Windows sign-off. Sleeper access remains tokenless and read-only: the app does not submit picks or change lineups. Supply your own ranking exports and a locally installed, authenticated Codex CLI for normal AI use; active drafts retain emergency board-only recovery.

Local data lives under `%APPDATA%\Sleeper Draft Assistant`. Settings provides import clearing and full reset. Keep a closed-app backup before destructive tests. Rollback can require reinstalling beta.3 and restoring its pre-upgrade backup while the app is fully closed.
