# Sleeper Draft Assistant 0.1.0-beta.2

This is a beta testing candidate, not a stable release. Back up local app data before upgrading. Manual clean-profile Windows testing of this version is pending; automated Windows packaging and startup checks do not replace that sign-off.

## Changes

- Accepts the verified FantasyPros Overall ROS CSV format, with draft ECR retained as a clearly labeled fallback.
- Adds optional AI-controlled NFL.com/ESPN news lookups with dated source links. Web search defaults on and can be disabled in AI settings. Searches may add latency and usage; unavailable recent reporting is reported as a gap.
- Improves draft synchronization for same-count pick corrections and rejects recommendations generated against an outdated board.
- Guards against stale responses after changing teams, settings, or resetting data; strengthens storage failure recovery.
- Improves dialog keyboard navigation, focus restoration, team data interactions, and desktop startup recovery.
- Updates dependencies to address the advisories identified during release preparation.

## Windows testing still required

- Upgrade with an existing profile; verify settings, imports, and history survive close/relaunch.
- Clean-profile launch, demo, Sleeper connection, native multi-file imports, and provider setup/recovery.
- Dialog keyboard behavior, smaller windows, and 125%/150% display scaling.
- Web-search setting persistence, source links, cancellation/context switching, and quitting during active AI/news requests without orphaned app-owned processes.
- Backup, reset, uninstall/reinstall, and rollback. Close the app before backing up or restoring its complete data directory.

## Installation and limitations

Download the Windows installer, portable executable, or ZIP and verify its SHA-256 against `SHA256SUMS.txt`. Builds are unsigned and may trigger SmartScreen. macOS is not supported; Linux development checks are not Windows desktop verification.

Sleeper access remains tokenless and read-only: the app does not submit picks or change lineups. Supply your own ranking/projection CSVs and a locally installed, authenticated Codex CLI for normal assistant use. Active drafts retain emergency board-only recovery when setup is incomplete. Validate advice yourself; custom scoring support is limited, and auction/IDP advice is unsupported.

Local Windows data lives under `%APPDATA%\Sleeper Draft Assistant`. Settings includes import-clearing and full-reset controls. Keep a full backup before upgrades or destructive tests; see [installation and rollback guidance](https://github.com/itsreverence/sleeper-draft-assistant/blob/v0.1.0-beta.2/docs/INSTALLING.md) and [privacy](https://github.com/itsreverence/sleeper-draft-assistant/blob/v0.1.0-beta.2/docs/PRIVACY.md).
