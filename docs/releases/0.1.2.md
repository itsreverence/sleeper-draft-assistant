# Sleeper Draft Assistant 0.1.2

This is a stable release following 0.1.1. It redesigns the draft room and Team
Manager, makes Assistant answers easier to read, and corrects who-picks-when in
linear, third-round-reversal, traded-pick and keeper drafts. The database schema
is unchanged. Releases before 1.0 may change stored data or behavior between
versions. Close 0.1.1 and back up the complete app-data directory before
upgrading.

## Changes

### Draft room

- The room now leads with your pick and the Assistant's call. A pick strip shows
  when you are on the clock or how many picks away you are. The recommendation
  and its backups come next, with recent picks and your roster beside them.
  The board sits below and shows the current and next round, and Full board is
  still available. See [#82](https://github.com/itsreverence/sleeper-draft-assistant/pull/82).
- The board is now a table for screen readers, and a real pick change is
  announced once. See [#84](https://github.com/itsreverence/sleeper-draft-assistant/pull/84).

### Pick order fixes

- Traded picks: unpicked board cells now name the team that owns the pick.
- Linear drafts were treated as snake, which gave wrong turn counts. They now
  use linear order on the board, in the pick strip and in what the Assistant
  sees.
- Third-round-reversal drafts now use reversal order, read from Sleeper's
  `reversal_round` setting. Sleeper does not document that setting. If reported
  picks contradict the computed order, the strip says "Pick timing unknown",
  though the board keeps its snake layout and current cell.
- Linear and reversal order were checked against synthetic drafts and completed
  public drafts, not a live draft in progress.
- The board no longer labels a pick "On the clock" before the draft starts.
  See [#84](https://github.com/itsreverence/sleeper-draft-assistant/pull/84).
- Keepers: pre-filled keeper picks no longer push the current pick forward, and
  "picks away" no longer counts filled keeper slots. This was tested with
  synthetic drafts only, not a live in-progress keeper draft.
  See [#85](https://github.com/itsreverence/sleeper-draft-assistant/pull/85).

### Team Manager

- The roster is now a table with Slot, Player, Week and Status columns, plus
  Proj when at least one rostered player has a projection. Bench, injured reserve
  and taxi are groups. During the regular season, the week and opponent sit beside
  the league name. A coverage footer can name an action that would improve your
  data. BYE is an amber chip.
- A weekly file that matched no players now reads "No match", not "No WR file".
  Readiness no longer reports that position as ready. A warning says whether no
  players matched or the file had no rows, and the Assistant is told the same.
  See [#81](https://github.com/itsreverence/sleeper-draft-assistant/pull/81).

### Assistant conversations

- Answers now render tables, numbered lists, bold, italics and inline code.
  Links are still limited to the same approved sites.
  See [#74](https://github.com/itsreverence/sleeper-draft-assistant/pull/74) and
  [#76](https://github.com/itsreverence/sleeper-draft-assistant/pull/76).
- Threads follow the newest message unless you have scrolled up to read.
- A Cancel button replaces Ask while an answer is pending. If the Assistant had
  already started, it finishes in the background and its answer isn't shown.
  Cancelled and failed questions are left out of follow-up history sent by the
  app, though the provider's own thread may still remember them.
  See [#77](https://github.com/itsreverence/sleeper-draft-assistant/pull/77).

### Wording, screens and consistency

- The AI is now called the Assistant throughout. "Codex" remains where it names
  the program you install and configure. Internal status codes are replaced by
  readable labels, and error messages say what to do next. An unknown Sleeper
  username now gets a clear message.
  See [#78](https://github.com/itsreverence/sleeper-draft-assistant/pull/78).
- A new visual system brings calmer type, consistent colors and better contrast
  for input borders and spinners.
  See [#75](https://github.com/itsreverence/sleeper-draft-assistant/pull/75).
- All five slide-out panels share one drawer, with a fixed header and the same
  width and phone layout. Draft plan and Team roster are wider, and Settings and
  Manage team data are narrower.
  See [#79](https://github.com/itsreverence/sleeper-draft-assistant/pull/79).
- Preparation has one primary button that takes you to the next unmet step.
  Projections and ADP now say "Required", as they always were for entering the
  draft room. File pickers are restyled and keep keyboard use and pasting.
  See [#83](https://github.com/itsreverence/sleeper-draft-assistant/pull/83).
- A completed league remembers Team Manager, so reloading no longer flashes the
  board. See [#84](https://github.com/itsreverence/sleeper-draft-assistant/pull/84).

## Tested platforms

This release has been tested only on Windows 11 Pro 26H2 (build 26300.9711).
It is tagged only after the every-release real Windows smoke passes on its exact
commit. Linux packaging and CI do not establish support on other Windows
versions or operating systems.

## Install safely

Artifacts are **not code-signed**, and Windows SmartScreen may warn that the
publisher is unknown. Download only from this repository's Releases page and
check each file's SHA-256 against `SHA256SUMS.txt` before running it. See
[INSTALLING.md](../INSTALLING.md). Third-party licenses are in
`resources\THIRD_PARTY_NOTICES.txt`.

## Requirements and limitations

- Sleeper is the only supported fantasy platform. Access is tokenless and
  read-only. The app does not submit picks, change lineups or modify your
  Sleeper account.
- You supply your own ranking and projection exports. No third-party ranking
  data is bundled.
- The normal assistant workflow requires a locally installed, signed-in Codex
  CLI, which the app runs through its supported app-server integration. During
  an active draft, board-only recovery remains available when setup or Codex is
  unavailable.
- AI advice is advisory; check it yourself. News lookups can still time out or
  find no recent reporting. Citation dates are reported by the model and are
  checked for format, recency and consistency with the link, but not against
  the publisher's page.
- Custom scoring and TE-premium accuracy depend on imports that match your
  league. IDP and auction drafts are unsupported. Dynasty and keeper valuation
  is not modeled. The app handles keeper pick order but does not value keepers.
- The app shows no pick timer, because it does not read one from Sleeper.
- The app has a dark theme only.
- Research threads disable Codex's built-in shell, browser, computer-use, app
  and plugin tools. They do not disable MCP servers you have configured in your
  own Codex setup.

## Local data and removal

Data normally lives under `%APPDATA%\Sleeper Draft Assistant`, with the database
in its `data` directory. Settings offers per-category clears and **Delete all
local app data**. The uninstaller keeps local data. Close the app before
deleting files by hand: delete `data` to remove your records, or delete the
whole directory to also remove renderer preferences.

## Rollback

0.1.1 and 0.1.2 can read each other's stored data. To roll back:

1. Close 0.1.2.
2. Restore the backup you made before upgrading.
3. Reinstall 0.1.1 from its original release.

Never restore a backup while either version is running. If you keep your 0.1.2
data instead of restoring, a weekly file imported on 0.1.2 that matched no
players can read as ready on 0.1.1 until you import weekly projections again.
