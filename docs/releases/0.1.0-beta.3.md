# Sleeper Draft Assistant 0.1.0-beta.3

This is a Windows follow-up testing beta, not a stable release. Manual Windows validation of these changes is pending. Back up the complete app data directory while the app is closed before upgrading.

## Fixes since beta.2

- Fixes player-search results being clipped instead of scrolling.
- Explains the Sleeper username requirement when connecting through a league URL.
- Corrects weekly CSV selection feedback: unknown filenames are no longer mislabeled as FLEX, FLEX/FLX files are skipped, and replacement inputs clear old errors. Pasting CSV replaces selected files; failed or superseded file reads cannot reuse old input.
- Accepts official NFL AMP article links in news validation, answer rendering, and the external browser handler. Arbitrary subdomains and unsafe URLs remain blocked.
- Adds up to 20 sanitized news-lookup outcomes and elapsed times to diagnostics/support reports. No player names, prompts, article contents, source URLs, local paths, or raw provider errors are included.

## Windows follow-up checklist

1. Upgrade beta.2 and confirm settings, imports, and history survive launch, shutdown, and relaunch.
2. In player search, search a broad term such as `a`, wheel over the results, and reach the last row. Repeat in a short window and at 125%/150% scaling. Check menu/dialog Escape and focus restoration.
3. Expand **Paste a league URL** and verify the username prerequisite is visible before submission.
4. Test invalid weekly CSV followed by valid replacement files, an unknown single filename, an unknown filename in a batch, FLEX/FLX, and switching from selected files to pasted CSV. Confirm new server errors still appear and successful imports work.
5. With web search enabled, ask about current injury/practice reporting for a player in the loaded snapshot. Check `newsLookups` in Copy diagnostics: an empty list is not a retrieval pass. Verify a returned NFL AMP source opens externally. Recheck web search off/on and quitting during an active request without leaving app-owned processes running.

The beta.2 Windows report is useful baseline evidence, but does not validate this installer. See the [validation follow-up](https://github.com/itsreverence/sleeper-draft-assistant/blob/v0.1.0-beta.3/docs/releases/beta.2-validation-followup.md) for reproduction details and test boundaries. Narrow-viewport T3 testing was interrupted by a browser-host disconnect and remains pending on Windows.

## Verification and limitations

The source fixes passed 411 automated tests, type checks, production builds, and dependency audits with zero vulnerabilities. Linux unpacked packaging and authenticated loopback API checks passed. A controlled live news-tool request returned validated dated sources within the unchanged 20-second budget after the NFL AMP fix; this does not guarantee retrieval success or latency on every request. The release workflow rebuilds and tests the tagged source on Windows before publishing artifacts.

Builds are unsigned and may trigger SmartScreen. Download the installer, portable executable, or ZIP from this release and verify its SHA-256 against `SHA256SUMS.txt`. macOS is not supported; Linux checks are not Windows desktop sign-off.

Sleeper support remains tokenless and read-only: the app does not submit picks or change lineups. Supply your own ranking/projection CSVs and a locally installed, authenticated Codex CLI for normal assistant use. Active drafts retain emergency board-only recovery. This is unofficial software, not endorsed by Sleeper, FantasyPros, or OpenAI.

Windows data is stored under `%APPDATA%\Sleeper Draft Assistant`. Settings provides import-clearing and full-reset controls. Keep a complete backup before upgrades or destructive tests; rollback may require reinstalling beta.2 and restoring its pre-upgrade backup while the app is closed. See [installation guidance](https://github.com/itsreverence/sleeper-draft-assistant/blob/v0.1.0-beta.3/docs/INSTALLING.md) and [privacy](https://github.com/itsreverence/sleeper-draft-assistant/blob/v0.1.0-beta.3/docs/PRIVACY.md).
